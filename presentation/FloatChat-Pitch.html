The problem

The ocean is measured. The data is public. Almost no one can use it.

  • ARGO — ~4,000 robotic floats have measured the ocean since 2000, adding 100,000+ profiles a year (3M+ total).
  • India's MoES / INCOIS both contribute floats and depend on this data for forecasts, fisheries, and climate. 4M+ fishermen need the same data but can't access it.
  • But it ships as NetCDF — domain-specific files opened only through specialist tools and query knowledge.
  • In practice a handful of trained scientists can use it. Everyone else is locked out.
The barrier

A researcher today needs to know the NetCDF conventions, QC-flag rules, delayed-mode vs real-time modes, pressure-vs-depth, and how to write the extraction code — before they can answer a single question.

FloatChat removes every one of those steps.

The solution

One question in. Answer, map, chart, and the SQL out.

  • Ask in English or an Indian language — plain words, no software, no formats.
  • Grounded answer — one plain sentence; every number comes from a real record.
  • See it — floats on a live satellite map, a depth or time chart, a results table.
  • Trust it — the exact SQL and the source WMO float IDs sit under every answer.
  • Follow up — the AI suggests the next questions; save any query for later.
  • Fisheries — PFZ advisories, SST, chlorophyll — fishermen ask about fish, not databases.

Trust — the reason a scientist will believe it

It never makes numbers up.

  • Grounded — every number is checked against the result set; nothing invented.
  • Single SELECT only — sqlglot parses it; DDL/DML and stacked statements are rejected.
  • Table allow-list + keyword denylist — only the four ARGO tables are reachable.
  • Read-only role + 5-second statement timeout — the query can look, never touch.
  • Transparent — the SQL and source float IDs are shown with every answer.
  • Offline-safe — a rule engine answers the common questions if the AI is unavailable.
Data quality, at ingest
  • Keep only QC flags 1–2; drop bad / missing readings.
  • Prefer delayed-mode adjusted values when their QC is good.
  • Convert pressure → true depth with TEOS-10.
  • Keep ascending profiles; tidy one row per level.

Fisheries intelligence — built in

The same engine, now for the people who fish.

  • Fishing zones (PFZ) — derived from live satellite data with the INCOIS recipe, overlaid on the float map. Fishermen ask "where should I go?" and get a grounded answer.
  • Satellite SST — daily NOAA OISST sea-surface temperature. "Is the water warm enough for tuna near Kochi?" → a real answer with data.
  • Chlorophyll / ocean colour — daily NOAA VIIRS chlorophyll-a identifies plankton blooms and productive grounds (ISRO OCM archives too).
  • Seasonal guide — species-specific tips by monsoon season, backed by real observations.
